# 🔐 Cyber Password Strength Checker

A cybersecurity-focused password strength analyzer built with Python.

This project evaluates password security using:

* Length analysis
* Character diversity
* Entropy estimation
* Weak password detection
* Pattern analysis
* Smart password suggestions

---

## 🚀 Features

✅ Password strength classification
✅ Entropy calculation (security estimation)
✅ Weak password detection
✅ Pattern analysis
✅ Smart password recommendations

## 🛠 Technologies Used

* Python
* Regex (`re`)

1. Clone the repository

```bash

```

2. Move into the folder

```bash
cd cyber-password-strength-checker
```

3. Run the project

```bash

```
